\# StudyFlow



StudyFlow is a full-stack MERN student task and study planner designed to help students organize their academic tasks, track progress, and manage due dates.



This project was built as a hands-on project to learn the fundamentals of the MERN stack.



\## Features



\- Add study tasks

\- View all tasks

\- Edit task titles

\- Delete tasks

\- Mark tasks as completed or pending

\- Search tasks

\- Filter by:

&#x20; - All Tasks

&#x20; - Pending

&#x20; - Completed

\- Set task priority:

&#x20; - Low

&#x20; - Medium

&#x20; - High

\- Select due dates using a custom calendar

\- Dashboard showing:

&#x20; - Total tasks

&#x20; - Completed tasks

&#x20; - Pending tasks

\- Persistent task storage using MongoDB

\- Responsive light claymorphism user interface
